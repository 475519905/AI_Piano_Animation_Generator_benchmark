# 指标定义（v0.1.0）

所有指标按独立完整演奏报告；默认不输出总分、排名或布尔合格结论。输入单位为米。
`T` 是帧数，`J` 是声明的点/关节数；预测和参考使用同一时间轴、坐标、ID 顺序。

## 1. 位置误差：不要混用 RMSE 和点距离

令 `d[t,j,c] = predicted[t,j,c] - reference[t,j,c]`。

- `coordinate_rmse_mm = 1000 * sqrt(sum(d²)/(3*T*J))`。
- `mean_point_error_mm = 1000 * sum(norm(d[t,j,:]))/(T*J)`。
- 三维点距离另报均值、p50、p95、max 及样本数。

当点就是同名骨骼关节时，第二项是本坐标协议下**未对齐**的 MPJPE；
不是根节点对齐、尺度对齐或 Procrustes 对齐的结果。三个轴各错 1 mm 时，
坐标 RMSE 是 1 mm，三维点误差是 sqrt(3) mm，不能使用同一名称宣传。

Micro RMSE 先汇总平方误差与坐标数，再开方；**不是各演奏 RMSE 的加权平均**。
Macro RMSE 是每段完整演奏 RMSE 的等权均值，两者名称明确区分。

## 2. 旋转误差

四元数顺序为 `(x,y,z,w)`，在副本上归一化：
`theta = 2 * acos(clip(abs(dot(q_pred,q_ref)),0,1))`，转成度。
绝对点积使 `q` 与 `-q` 代表同一旋转。零/近零或无法有限归一化的四元数拒绝输入。
报告不改变原数组；无参考旋转则 `not_measured`。

## 3. 指法与时序

手指标签：右手拇指至小指 0–4，左手拇指至小指 5–9。
参考必须是 0–9，预测允许 -1 表示弃权。弃权计入错误和覆盖率，不能靠漏预测提高准确率。

- 指法准确率：相同事件 ID 上标签相等的数量 / 全部参考事件。
- 左右手准确率：双方 `label // 5` 相等；预测弃权仍为错误。
- 混淆矩阵：参考 10 行，预测 0–9 加弃权列，共 11 列。
- Onset：相同事件 ID 的预测起始秒减参考起始秒；报告有符号均值、绝对偏差均值/p50/p95/max，单位 ms。

这不是音符检测任务：不自动匹配音符，不把缺失/额外事件藏在最近邻匹配中；
事件 ID/顺序不一致会拒绝。v0.1 不计算释键、踏板或替代指法合理性。
正确演奏可以有不同于单一参考的合法指法，因此标签一致性不能单独代表可演奏性。

## 4. 参考指法条件下的接触代理（严格限定范围）

参考提供每帧每指是否应接触、目标键索引及键包围盒；这些不能从被测模型自己的接触声明反推。
预测只提供实际求值指尖位置。键包围盒可以静态，或逐帧包含按键下沉。

对有效参考接触：
- XY：指尖 X/Y 均位于目标键最小/最大边界内；只满足 X 不算命中。
- Z：指尖 Z 与键包围盒顶部 Z 的绝对差不超过预先声明的 `contact_tolerance_mm`。
- 同时满足 XY 与 Z 才计入 `surface_contact_ratio`。
- `target_key_point_penetration_mm` 在 XY 内计算 `max(key_top_z-tip_z,0)*1000`。

**这只是指尖点—目标键轴对齐包围盒顶面的代理，不是皮肤/指尖体积与真实键面的碰撞检测。**
白键非矩形、黑白键重叠、指腹半径、侧面擦碰、自碰撞、非活动指触到其他键均不能靠它认证。
参考指定的手指与模型采用的合法替代手指不同，也会产生代理错误。
要评估任意手指完成 MIDI 键事件，应另外实现独立的音符级几何匹配；v0.1 未实现。

无参考接触样本时返回 `not_measured`，不是 100% 命中。
没有 XY 内样本时穿入深度统计也为缺失，不默认成 0。
完整网格碰撞一律单独标记为未测；不能把该代理冠名“无穿模率”。
示例使用 2 mm 仅为算术演示，**不是通用验收标准**。

## 5. 运动变化与持键 jerk

均匀帧间隔 `dt=1/fps`，对原始轨迹不隐式滤波：
- `speed = norm(diff(position))*1000*fps`，mm/s；
- `acceleration = norm(diff(position,n=2))*1000*fps²`，mm/s²；
- `jerk = norm(diff(position,n=3))*1000*fps³`，mm/s³。

三阶差分使用 4 个样本。持键 jerk 只纳入这 4 个样本全为参考持键状态的区间；
样本不足/没有这样的区间，输出缺失。普通 jerk 包含起音/释键阶段，两者不可混报。

按秒计消除了简单的单位差异，**并不保证不同采样率、滤波/插值策略所得统计完全相同**。
低 jerk 可能只是僵硬/静止，强起音本来就可能有较大加速度。只能联合其他测量与人工评审解释。

## 6. 缺失、无效与汇总

- 没有数据：`status=not_measured` + 原因/样本数，数值不伪填为 0。
- 时间/ID 不一致、NaN/Inf、错误单位、非法键索引等：拒绝评测，不能继续打印“通过”。
- Micro 按点/事件/有效接触计数汇总，Macro 每个完整演奏等权。
- 汇总报告同时标注 measured/missing performance 数量，不平均 p95 等分位数。
- 不允许同一 performance 的任意片段重复参与 Macro；同一组须保持帧率、阶段、指法条件、split、后处理和接触容差一致。
- 本版不提供 FID、分布相似性、关节生理安全性或统一“自然度分数”。
